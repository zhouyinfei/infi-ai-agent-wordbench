# 文件与联网工具

工具通过 Spring 自动注册，工作台工具列表自动展示。ReAct、Plan-and-Execute 均可调用全部工具；Multi-Agent 新增 FILE 文件角色和 NETWORK 联网角色，由协调 Agent 分配任务。

| 工具 | 参数 | 行为 |
| --- | --- | --- |
| file_create | path, content | 创建 UTF-8 文件并自动创建父目录；已存在则失败 |
| file_read | path | 读取 UTF-8 文件 |
| file_write | path, content | 覆盖已有文件；文件不存在则失败 |
| file_delete | path | 永久删除单个普通文件，不递归删除目录 |
| file_list | path | 浏览目录，`.` 表示根目录，最多展示 200 项 |
| http_get | url | 获取公开 HTTP(S) 文本、HTML、JSON、XML，不跟随重定向 |
| web_search | query | 启用 Tavily 后按关键词搜索，返回标题、来源链接与摘要 |

文件根目录默认为启动目录下的 `tool-workspace`，通过环境变量 `TOOL_FILES_ROOT` 或配置 `app.tools.files.root` 修改。路径必须是根目录内的相对路径；拒绝越界及链接。单文件读写上限 64 KiB，内容须为 UTF-8。

**文件目录由所有用户和会话共享**，适合受信任用户的工作台，不提供用户文件隔离。删除不可恢复，写入会覆盖原内容。部署时请使用专用目录，不要指向源码、系统目录或凭证目录；不要让其他本机进程在执行期间改换目录或链接。

`http_get` 无域名白名单限制，可读取任意公开网站，无需设置 `TOOL_HTTP_ALLOWED_HOSTS` 或 `app.tools.http.allowed-hosts`（旧配置不再生效）。本机、私网地址仍被拒绝。部署网络层也应限制内网出站访问，以防 DNS 在校验和连接之间发生改变。

`http_get` 只支持标准 80/443 端口、无 URL 凭证的 GET，不发送业务 Cookie、令牌或模型 API Key。响应上限 64 KiB，连接和读取等待各 5 秒，读取循环另有 10 秒总预算。响应须为 UTF-8；HTML 保留原文，不执行脚本。网页内容作为不可信数据反馈给模型。

## 关键词搜索（Tavily）

搜索默认关闭，关闭时不注册 `web_search`，其他工具仍可使用。在启动后端的 PowerShell 会话设置：

```powershell
$env:TOOL_SEARCH_ENABLED = 'true'
$env:TAVILY_API_KEY = '<你的 Tavily API Key>'
$env:TOOL_SEARCH_MAX_RESULTS = '5'
mvn spring-boot:run
```

IDEA 启动时，在运行配置的环境变量中设置这些值，然后重启后端。不要将真实 Key 写进源码或前端。启用后缺少 Key、结果数量不在 1 到 10 之间时启动失败，避免误以为搜索可用。

工具固定向 `https://api.tavily.com/search` 发送 POST，使用后端 Key 鉴权；搜索关键词会发送至 Tavily。采用 basic 搜索，不请求原始全文或生成答案。服务器须能访问 Tavily。连接超时 5 秒，读取等待 10 秒，读取循环另有 10 秒预算；响应上限 256 KiB，每条标题最多 300 字符、摘要最多 2000 字符（超长时附省略号）。工具不回传完整服务端错误正文或凭证。

ReAct、Plan-and-Execute 可自动选择搜索；Multi-Agent 由 NETWORK 角色执行。未知具体 URL 时先搜索，回答附实际结果中的来源链接。搜索结果为空、鉴权失败或限流时如实报告。搜索只返回摘要，不自动抓取结果网页；可进一步调用 `http_get` 读取公开网页原文，无需配置域名。

验证步骤：

1. 配置环境变量并重启，确认工作台工具列表包含 `web_search`。
2. 在 ReAct 输入“请调用 web_search 搜索 Java 25 官方发布说明，列出三个要点并附来源链接”。
3. 展开“查看执行详情”，确认工具名为 `web_search`、参数包含 `query`，观察结果包含实际标题、URL 和摘要，回答引用相同来源。
4. 分别在 Plan-and-Execute、Multi-Agent 中验证，后者应由 NETWORK 执行；仅有最终回答不能证明已联网。
5. 无 Key 时保持搜索关闭；测试错误 Key 的鉴权失败、空结果和服务限流，确认不会编造成功结果。

自动化测试使用本地 HTTP 替身，不消耗 Tavily 配额、不需要真实 Key：

```powershell
mvn '-Dtest=WebSearchToolTest,HttpGetToolTest,ExtendedToolsTest' test
```

接口参考：[Tavily 官方搜索说明](https://help.tavily.com/articles/4840311948-tavily-search-api)。

示例任务：

- “创建 notes/hello.txt，内容为你好，再读出来。”
- “将 notes/hello.txt 覆盖为新的内容。”
- “列出工具根目录。”
- “删除 notes/hello.txt。”
- “获取 https://example.com/ 的内容并总结。”（无需配置域名）
